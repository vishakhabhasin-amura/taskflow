# TaskFlow

A minimal to-do list application, implemented three ways for the Agentic AI SDLC workshop.
All three implement the same API contract and data model, so any pod can work from whichever
language they're given.

- [Node/](Node/README.md) — Node.js + Express
- [java/](java/README.md) — Java + Maven
- [python/](python/README.md) — Python + Flask

See each folder's own README for that implementation's run/test instructions.
